## Classroom: първа версия за преглед

Добавя Jekyll основа за учебни материали: начална страница и страници за 9. клас (C++) и 11. клас (Java), с почти бял фон, синьо-тюркоазена палитра и лавандулови акценти.

Класовете, разделите, уроците и ресурсите се описват в YAML. Всеки клас има два примерни публикувани урока с теория, задачи, домашна работа и самостоятелен HTML ресурс. Черновите и разделите само с чернови не се показват. Разделите са изрично демонстрационни до проверка на програмите на МОН.

Навигацията използва номерирана времева линия, карти, ресурсни бутони, сгъваеми раздели и отметки с localStorage. Ключовете използват постоянни ID, независимо от заглавие и подредба. Блокирано хранилище не прекъсва работата; има синхронизация между отворени браузърни раздели. Challengers е използван само като архитектурна справка и не е променян. Визуалният прототип не се отвори през уеб инструмента; следвано е описанието на дизайна.

## Проверки

- `bundle exec jekyll build --strict_front_matter` — успешно.
- `bundle exec ruby tests/site_test.rb` — 3 теста, 362 assertions, без грешки: ID, филтриране, ресурси, локални връзки/котви под `/classroom/`, Markdown, HTML.
- `node --test tests/progress.test.cjs` — 6 успешни теста: записване/възстановяване, премахване на отметки, блокиран localStorage, празен курс, сгъване, cross-tab синхронизация и начална страница.
- Браузър: начална страница, преминаване между класовете, отметка и запазване след reload, сгъване/разгъване; мобилен viewport 390×844 без хоризонтално преливане на страницата за клас.
- `git diff --check` — без грешки.

GitHub Actions добавя само build/test проверки. Няма deploy workflow. GitHub API потвърди `has_pages: false`; сайтът не е публикуван и Pages не е активиран. PR не трябва да се слива/публикува преди преглед и одобрение.

Ограничение: отметките са локални за браузъра. Скриването от навигацията не е контрол на достъпа; за черновите няма добавени публични файлове. README описва добавянето на материали, постоянните ID и локалното стартиране.
